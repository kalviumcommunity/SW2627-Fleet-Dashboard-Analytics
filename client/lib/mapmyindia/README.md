# MapmyIndia Integration

This directory will contain the logic for integrating with the **Mappls API by MapmyIndia**. Mappls provides a comprehensive suite of mapping, location, routing, and SDK services designed for highly accurate and scalable map-based applications in India.

For official documentation, please refer to the [Mappls Developer Portal](https://about.mappls.com/api/).

**Environment Variables Required:**
- `MAPMYINDIA_API_KEY`
- `MAPMYINDIA_CLIENT_ID`
- `MAPMYINDIA_CLIENT_SECRET`

*Note: Never commit actual keys or secrets to the repository. Use `.env.local` for local development.*
